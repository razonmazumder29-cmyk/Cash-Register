ওয়েব-লিংক সংস্করণ - হেড অফিসের জন্য নির্দেশিকা
================================================

এই ফোল্ডারটি একবার ইন্টারনেটে আপলোড করলে একটি স্থায়ী লিংক পাবেন।
সব শাখা সেই লিংক খুলে ব্যবহার করবে। হিসাব প্রতিটি শাখার নিজের কম্পিউটারেই থাকবে,
কোনো সার্ভারে যাবে না। এক শাখার হিসাব অন্য শাখায় যাবে না।

পদ্ধতি ক (সহজ): Netlify Drop
  1. ZIP এক্সট্র্যাক্ট করুন।
  2. https://app.netlify.com/drop খুলুন।
  3. এক্সট্র্যাক্ট করা "CashRegister_Web" ফোল্ডারটি পেজে টেনে ছেড়ে দিন।
  4. একটি লিংক পাবেন (যেমন: কিছু-একটা-নাম.netlify.app)।
  5. জরুরি: বিনামূল্যে অ্যাকাউন্ট খুলে সাইটটি "claim" করুন, নইলে কিছুক্ষণ পর সাইট মুছে যাবে।
  6. পরে নাম বদলাতে: Site configuration > Change site name।
  7. নতুন ভার্সন দিতে: সাইটের Deploys পেজে নতুন ফোল্ডার আবার টেনে ছাড়ুন।
     (সাথে sw.js ফাইলের VERSION-এর সংখ্যা বাড়ান, যেমন cashreg-v2)

পদ্ধতি খ: GitHub Pages (স্থায়ী ও বিনামূল্যে)
  1. github.com-এ অ্যাকাউন্ট খুলে নতুন repository তৈরি করুন।
  2. এই ফোল্ডারের সব ফাইল আপলোড করুন (Add file > Upload files)।
  3. Settings > Pages > Branch: main > Save।
  4. কিছুক্ষণ পর লিংক পাবেন: https://আপনার-নাম.github.io/repository-নাম/

শাখাগুলো কী করবে
  1. লিংকটি Chrome, Edge বা Firefox-এ খুলবে।
  2. প্রথমবার সেটআপ উইন্ডোতে শাখার নাম, পাসওয়ার্ড ও রিকভারি কোড দেবে।
  3. Chrome/Edge: ঠিকানা-বারের ডানে "Install" আইকন বা মেনু > Install থেকে অ্যাপ হিসেবে ইনস্টল করবে।
  4. সেটিং থেকে "অটো-ব্যাকআপ" চালু রাখবে এবং ব্যাকআপ ফাইল পেনড্রাইভে রাখবে।

গুরুত্বপূর্ণ
  - লিংকটি জানা থাকলে যে কেউ অ্যাপটি খুলতে পারবে, কিন্তু কারও হিসাব দেখতে পারবে না,
    কারণ হিসাব শুধু ওই কম্পিউটারের ব্রাউজারে থাকে।
  - একই লিংক ও একই ব্রাউজারে সবসময় ব্যবহার করুন। লিংকের ঠিকানা বদলালে আগের হিসাব দেখা যাবে না।
  - আগে HTML ফাইল দিয়ে যারা কাজ করেছে, তারা পুরনো ফাইল থেকে "ব্যাকআপ নিন" করে
    নতুন লিংকে "রিস্টোর করুন" দেবে। ডেটা আপনা-আপনি আসবে না।
